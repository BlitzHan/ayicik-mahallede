# Ayıcık Mahallede

4-5 yaş için Türkçe, sesli, tarayıcıda oynanan 3D ayıcık oyunu (three.js, derlemesiz).

Oyna: https://blitzhan.github.io/ayicik-mahallede/

Aile verileri (çocuk adı, fotoğraf, ses, kıyafet) yalnız cihazda saklanır; bu depoda yoktur.

## Sesler

- Konuşmalar: Microsoft Edge Neural TTS (tr-TR-EmelNeural) ile önceden üretildi.
- Efektler: Kenney.nl ses paketleri (CC0).
- Müzik (CC0, OpenGameArt): "Children's March Theme" (cleytonkauffman), "Happy Adventure (Loop)" (tinyworlds), "Flowerbed Fields [Loop]" (Zane Little Music), "Happy Lullaby" (cynicmusic).
